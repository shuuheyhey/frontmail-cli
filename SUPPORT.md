# Support

## Front CLI bugs and usage questions

Use [GitHub Issues](https://github.com/shuuheyhey/frontmail-cli/issues) for a
reproducible CLI bug or a question about documented Front CLI behavior. Search
existing issues first and include the CLI version, operating system, command
shape, expected result, and redacted output.

Never include Front API tokens, customer messages, attachments, email
addresses, or other private data. Replace production identifiers with
synthetic values such as `cnv_123` and `user@example.com`.

## Front product and API support

This project is not affiliated with Front. For Front account, billing,
permissions, product behavior, or API availability questions, use the
[official Front developer documentation](https://dev.frontapp.com/) and Front
support channels.

Security vulnerabilities belong in a private report under the
[Security Policy](SECURITY.md), not a public support issue.
