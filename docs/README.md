# Documentation

Front CLI is a read-only, JSON-first client for the Front Core API. Choose the
shortest route for what you need.

## Use Front CLI

1. [Getting started](getting-started.md) — install, configure, and run the first
   commands.
2. [Configuration](configuration.md) — environment variables, config files,
   secret managers, and precedence.
3. [Command reference](commands.md) — commands, flags, pagination, completion,
   and examples.
4. [Output format](output-format.md) — JSON envelopes, errors, and
   `next_actions`.
5. [API support](api-support.md) — resource and relation mappings pinned to the
   official Front specification.
